# HappyArif License Guard

A secure, universal license verification package designed for Laravel applications, Custom PHP apps, and WordPress Plugins/Themes.

## Installation

Add this package to your project via Composer by declaring it in your `composer.json`:

```json
"repositories": [
    {
        "type": "vcs",
        "url": "https://github.com/happyarif/license-guard.git"
    }
]
```
Then run:
```bash
composer require happyarif/license-guard
```
